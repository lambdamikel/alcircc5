Round-9 split-forest proof repair package

This package responds to the Opus 4.8 review of the round-8 saturated-side-context proof.
It accepts the central D-1 defect and repairs both the extended proof and the compact proof sketch.

Main repair:
- Selected DR/PO side witnesses are first tested for composition-forced verticalization.
- If an ancestor trace has a PPI tail, an occurrence/equality mate of the witness is spliced into the generated cover relation E_up at a bounded threshold.
- The source-witness relation remains the inherited DR/PO side/frontier relation.
- Deep tail pairs are represented by equality-aware vertical reachability, not bounded side contexts.
