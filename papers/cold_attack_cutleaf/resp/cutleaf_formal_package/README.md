# Cut-leaf residue: formal note and artifacts

This package accompanies **Serving Cut Leaves in the forall-PO-Free Fragment of ALCI-RCC5: Support-Generated Labels, Extremal Carriers, and Demand-Carrying Kernels**.

## Main deliverables

- `cutleaf_residue_note.pdf` - the 14-page formal technical note.
- `latex/cutleaf_residue_note.tex` - complete LaTeX source.
- `original/archive/cold_attack_cutleaf.zip` - the supplied archive, preserved verbatim.
- `original/` - clean unpacking of the supplied prompt, Lean excerpt, and probes `wp112` through `wp118`.
- `candidates/probes/` - new probes `wp119`, `wp120`, and `wp121`.
- `candidates/lean/CANDIDATE_LEMMAS.lean` - commented Lean interface and proof-plan sketch; it makes no compilation claim.
- `outputs/reproduced/` - fresh outputs from all eight probe executions, including elapsed time and exit status.
- `outputs/provided/` - the originally provided outputs for `wp119` and `wp120`.
- `MANIFEST.sha256` - SHA-256 checksums for all package files except the manifest itself.

## Evidence status used in the PDF

- **[C]**: reported Lean-certified in the supplied complete development; the excerpt was inspected but cannot compile standalone.
- **[M]**: mathematical lemma proved in the note from the stated RCC5 order assumptions.
- **[E]**: probe result reproduced in this environment with its stated controls.
- **[O]**: open conjecture, construction interface, or unmechanized proof obligation.

The note does **not** claim a decidability proof. Its candidate repair has two parts:

1. use demand-supported Hintikka labels instead of complete model types; and
2. serve a vertical demand by an extremal carrier when one exists, otherwise by a kernel whose period carries that demand itself.

The unresolved theorem is a `C0`-computable bound, or regular compilation, for support generated by universals and mixed PP/PPI alternation.

## Reproduce probes

```sh
./scripts/run_all_probes.sh
```

Outputs are written to `outputs/rerun/` unless another destination is supplied:

```sh
./scripts/run_all_probes.sh /tmp/cutleaf-rerun
```

## Rebuild the PDF

A TeX Live installation with `latexmk`, TikZ, `tcolorbox`, and the standard AMS packages is required.

```sh
./scripts/build_pdf.sh
```

## New negative-control probe

`wp121_support_multitier_acceptance.py` checks every non-vacuous `MultiTierOk` field for the two-external fence certificate. Removing the witness argument produces exactly one `e_ex` failure; restoring it produces no failures for all tested fence lengths. This is a finite-family acceptance result, not a general completeness theorem.
