# New verification artifacts

These scripts use only Python 3's standard library.

- `target_a_class_top_counterexample.py` checks the concrete ordered-disjoint
  counterexample to a type-only common class top.
- `target_b_finite_rectangle_lemma.py` checks the RCC5 transition-rank facts used
  by the finite fusion proof and illustrates why infinite tail rectangles fail.
- `target_c_selection_circularity.py` checks the one-kernel counterexample to the
  tail-stabilize/add-witness fixed-point strategy.

The scripts deliberately distinguish finite executable evidence from the general
paper arguments in the report.
